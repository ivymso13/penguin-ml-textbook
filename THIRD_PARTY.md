# External materials

## Penguin data

`reference/penguins_size.csv` is the user-supplied teaching CSV, copied unchanged into the lesson.
Distribution source: https://www.kaggle.com/datasets/parulpandey/palmer-archipelago-antarctica-penguin-data
Original observations: Kristen Gorman and Palmer Station Antarctica LTER.
The upstream Palmer Penguins project identifies its datasets as CC0:
https://allisonhorst.github.io/palmerpenguins/#license
The supplied CSV is a derived edition with different column names and categorical spellings.

## Runtime

JupyterLite, JupyterLab, Pyodide and Python packages retain their respective upstream licenses.

Project dependencies and versions are listed in requirements*.txt and jupyter-lite.json.

The original illustrated reference notebook is retained locally and is not included in this public repository.
